Packhouse settings
Lines and pallet sizes arrive here with their modules. The sulfur tents and acid baths have their own pages.
Tents
The tents on the sulfur screen, and what each one starts with. A tent that is no longer used is switched off, never deleted, so its past runs keep its name.
Suggested time and aril SO₂
The numbers behind the suggested time on each tent card. There is no published formula for litchi sulfur time, so these are a starting rule to tune: the operator always sees the reasons and can change the time. Set both percentages to 0 and every variety to 1.0 to suggest each tent's own default time.
Baths
The baths on the acid screen, and what each batch starts with. The screen warns when the chemicals are due: the SOP asks for at least two changes a week, so 3.5 days, or 500 crates. A bath that is no longer used is switched off, never deleted, so its past batches keep its name.
Data Backup
Backs up the packhouse data. Runs automatically every day at 02:00, but only saves a backup when something actually changed that day - quiet days add no entry. The last 14 are kept. Backup Now always creates one. If Boord copies its backups off this PC, these go to the same folder.
